# [ST-002] Legacy bhavcopy 2014–Jul 2024 + UDiFF gap + validated readers
[← index](../TECH_DEBT.md)

**What:** one-time history so `core/prices.py` returns NSE equity OHLCV for any trading day from 2014-01-01.

| Period | Format | Location (prod) | How it got there |
|---|---|---|---|
| 2014-01-01 .. 2024-07-05 (+7 weekend sessions) | legacy `cm…bhav.csv.zip` | `data/bhavcopy_legacy/` | `ingestion/fetch_legacy_bhavcopy.py`, 2026-10-08 |
| 2024-01-03 .. 2025-08-27 | UDiFF | `data/bhavcopy_udiff/` | MyInvestIQ's own fetcher, then moved out of its archive (`scripts/relocate_udiff_gap.py`) |
| 2024-01-01, 01-02, 03-01, 05-02, 06-28; 2025-08-28 onward | UDiFF | MyInvestIQ `data/bhavcopy/` (read-only) | MyInvestIQ |

**Decisions:** start 2014; copy (not import) MyInvestIQ's UDiFF parsing; data lives in strategy-trader's own
folder (Rakesh, 2026-10-08 — MyInvestIQ's folder structure is for MyInvestIQ only, shared data is read-only).

**Prod results 2026-10-08:** 2,597 legacy files OK, 153 weekday 404s all NSE holidays, 1 INVALID
(2020-07-13, `13-Jul-20` TIMESTAMP) fixed in code and re-fetched. Validation PASS: overlap 125 dates,
267,237 symbol-days, 0 mismatches, traded_value units equal. 19 `file_but_no_nifty_close` rows are
yfinance gaps (New Year, Muhurat, special sessions), not ours.

**Known limitation:** some weekend special sessions (e.g. Sunday Muhurat) may be missing; impact negligible.

**Done when:** `python -m scripts.validate_legacy_bhavcopy` prints RESULT: PASS with >= 100 overlap dates compared.
**Fail if:** any OHLC/volume mismatch in the overlap; any weekday 404 on a day Nifty traded; any ERROR/INVALID
manifest row; or `core.prices.read_ohlcv_for_date()` raises "missing" for any trading day 2014-01-01..today.
