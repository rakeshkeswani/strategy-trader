# [ST-013] Symbol changes (stitch renames via ISIN)
[← index](../TECH_DEBT.md)

A rename changes the NSE symbol but usually keeps the ISIN; a split changes the ISIN but keeps the symbol.
Detect a rename as: symbol A last trades on day D, symbol B first trades on the next session with the same ISIN.
Cross-check against NSE's published symbol-change list. Mergers (symbol and ISIN both vanish) stay delistings.

**Done when:** to be written with the design.
