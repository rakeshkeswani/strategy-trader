**Raised 2026-10-14 (Rakesh).** Specs below accepted as the starting point; details to be worked out when we get here.
Not in the plan doc — new scope.

## A. stratrad dashboard (this issue)
- **Shows:** status of each strategy; live P&L **net of charges**; costs (`order_charges`); return vs the Nifty 500;
  rolling 12-month loss and its tier (ok / alert / no-buys / halt); exposure by strategy and by sector against the caps
  (Rs 40,000 / Rs 25,000) and the Rs 1,00,000 total; guardrail blocks; backtest vs live for each strategy.
- **Data:** the `stratrad` database (`daily_snapshots`, `positions`, `order_charges`, `guardrail_events`) + backtest
  outputs (`data/backtests/<run_id>/`). See `docs/DATA_MODEL.md`.
- **Timing:** a backtest view first, after ST-010; the live view after the execution issues (ST-006/008/009).

## B. General market dashboard (performance of stocks, sectors, indices) — discussion point
- MyInvestIQ already collects the same prices and indices daily and is a stock-intelligence product; B may belong there,
  or should reuse its data rather than duplicate it in stratrad. **Rakesh to decide when we get here.**
