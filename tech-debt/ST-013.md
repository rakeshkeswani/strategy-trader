# [ST-013] Symbol changes (stitch renames via ISIN)
[← index](../TECH_DEBT.md)

A rename changes the NSE symbol but usually keeps the ISIN; a split changes the ISIN but keeps the symbol.
Detect a rename as: symbol A last trades on day D, symbol B first trades on the next session with the same ISIN.
Cross-check against NSE's published symbol-change list. Mergers (symbol and ISIN both vanish) stay delistings.

**Scope moved to ST-003 (Rakesh, 2026-10-11):** the rename list itself — one-time fetch of NSE `symbolchange.csv`
(`ingestion/fetch_symbol_changes.py`) and `core/symbol_changes.py` ("which symbol did this company trade under on
date X"). ST-003 needed it first: the corporate-actions feed reports past actions under the company's CURRENT
symbol (e.g. INFIBEAM's 2021 bonus is filed under CCAVENUE). **ST-013 keeps:** stitching each company's price
series across renames into one continuous history, using `core/symbol_changes.py` plus the ISIN-continuity check.

**Done when:** to be written with the design.
