# [ST-003] Split/bonus adjustment (corporate actions)
[← index](../TECH_DEBT.md)

**Agreed so far (2026-10-08):** single source of truth per period — MyInvestIQ owns ongoing corporate actions
(daily fetch is a MyInvestIQ TD Rakesh logs; it also backfills its table from 2025-08-26); strategy-trader fetches
history 2014..2025-08 once into `data/corporate_actions/`. Reader merges both; MyInvestIQ wins on the same
(symbol, ex_date, type). Read MyInvestIQ via a read-only DB role (ST-012).
Checks: jump scan, legacy PREVCLOSE cross-check, yfinance spot check. Out of scope: demergers, mergers, rights.

**Done when:** to be finalised with the design — must include a falsifying clause (e.g. a >35% one-day drop on a
known split date still present after adjustment = fail).
